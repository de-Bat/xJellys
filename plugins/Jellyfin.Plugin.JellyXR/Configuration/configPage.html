JellyXR

X-Ray style cast cards. Pause on Android TV and the actors appear as a message. "On screen" needs a one-time face scan (Dashboard → Scheduled Tasks → Scan videos for cast faces, or automatic when an item first plays). Cast portraits must exist in Jellyfin. Instead of (or as fallback to) the local scan, scene data can come from an Xrayarr server.

Per show scope

Scope: Scene = people on screen around the pause, Episode = whole cast, Current = scene, or whole cast when no scene data, Off = no cards. Shows without a rule use the default scope above.
