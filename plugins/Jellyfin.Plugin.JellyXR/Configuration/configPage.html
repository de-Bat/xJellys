JellyXR

X-Ray style cast cards. Pause on Android TV and the actors appear as a message. "On screen" needs a one-time face scan (Dashboard → Scheduled Tasks → Scan videos for cast faces, or automatic when an item first plays). Cast portraits must exist in Jellyfin. Instead of (or as fallback to) the local scan, scene data can come from an Xrayarr server.

Edits jellyfin-web's index.html, or uses the File Transformation plugin when installed (needed if the web folder is read-only). Not available in the Android TV app.
Needs the JellyTvOverlay app and plugin (or the older JellyXR TV companion app) on the Android TV box. Devices without the app keep getting text messages. Use one app per TV: with both JellyTvOverlay and the old JellyXR TV app installed you get two panels, so uninstall JellyXR TV.
Off: the panel appears by itself on pause and the remote keeps driving the player. On: pausing offers the panel and it opens with ▲ ▼ / OK on the cast list, while Play/Pause and ◀ ▶ (seek) keep going to the player. A double pause (pause, play, pause within 4 s) always offers it, fully interactive: it holds the remote (◀ ▶ flip pages). BACK always closes the panel and gives the remote back.
A small chip in the top right corner for 6 seconds ("Pause to see the cast"). Only on TVs with the JellyTvOverlay app, and not for shows whose scope is Off.
The tag works as a library filter in every client, including the Android TV app. Kept up to date after each scan and by the scheduled task Mark items with X-Ray data (run it after changing these settings).
The genre line is the only place the Android TV app shows it on the item page. It mixes into the real genres; a metadata refresh that replaces all metadata removes it until the next marker run.
Shows in every client wherever the image is shown, including the Android TV grids and rows. Your image files are not changed: a badged copy is kept in the plugin data folder and the item points at it; switching this off (then running the marker task) points it back. Needs the tag setting above. A library scan or image refresh can put the plain image back until the next marker run; clients may show a cached image for a while. Series and season posters get no badge.
Renaming leaves the old tag/genre on items until the marker task runs.

Per show scope

Scope: Scene = people on screen around the pause, Episode = whole cast, Current = scene, or whole cast when no scene data, Off = no cards. Shows without a rule use the default scope above.
