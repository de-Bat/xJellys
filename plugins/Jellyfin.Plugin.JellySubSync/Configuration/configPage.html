Shift subtitles from the TV remote. In Jellyfin on Android TV, with the JellyXR TV app (1.2.0 or newer) running, pause, play and pause again within 4 seconds: a sync box opens. Left / right moves the subtitles by 0.25 s, up / down by 1 s, OK applies and resumes playback on a "Synced" copy of the track. The original track is never changed; set the offset back to 0 to remove the copy.

Off: the synced file goes into Jellyfin's metadata folder and the media folders stay untouched. On: it goes next to the video file, which needs write access for the Jellyfin user. Turn on only if the synced track does not show up.
The synced track is shared by every user of the server.
